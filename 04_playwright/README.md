# CYPRESS

Using `cypress` to test simple webpage.  

## Created

```sh
npm init playwright@latest
```

## Configure or Run Project

```sh
nvm use
#or 
just nix 
```

Install and run  

```sh
just install

just test

npx playwright show-report
```
